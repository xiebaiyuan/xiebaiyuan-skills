# 中文输出的风格块与词表（单一来源）

这份文件是中文输出风格的权威版本。全局文件（`~/.claude/CLAUDE.md`、`~/.codex/AGENTS.md`、`~/.dsh/AGENTS.md`）里放的是精简后的常驻版加一条指针，指到这里；要改规则改这里，再同步全局文件里的那 20 行。

经过 `writing-for-agents` 优化：正文比第一版短 20%（2059 B → 1637 B），四个要点各自锚了一个预训练概念（先摆假设、最小可用、最小 diff、目标可验证），否定句只留在硬护栏位置，标语式口号全部删掉。

## 常驻版（全局文件里就是这段，20 行）

```markdown
## 改代码的准则
- 先摆假设：动手前把假设说出来，不确定就问，有多种解释先摆出来别自己挑；更简单的做法直接说。
- 最小可用：只写要求里的东西，不加抽象、不加配置项、不为不可能的场景兜底。200 行的活能 50 行写完就重写。
- 最小 diff：每一行改动都能追溯到本次要求；不动相邻代码，不重构没坏的东西。
- 目标可验证：把任务翻成验收标准（"先写测试再让它过"），多步任务先列"步骤 → 怎么验证"。

## 中文输出：说人话
先说受众：受众越广，句子越短越直白。对外文档默认读者是小白，缩写首次出现给全称；内部设计文档可以默认读者懂上下文，但不用只有团队懂的指标名和项目代号。看不懂的表达先问，别猜。

四类说法换成直白的：比喻当术语（击穿、扛住）、生造词（自解释度、容灾力）、过度缩写（高负、微服）、抽象空泛（赋能、颗粒度）。完整清单和例示范：本技能目录下的 `references/global-style-block.md`

引号只用于引用和标示专名、简称，不给黑话和口号加引号做强调。结论直接说，不用“不是A而是B”这种对照句（纠错时除外）。

定稿前自检，要求零命中：
rg -n "不是.{0,20}而是|击穿|打穿|扛住|接住|拉齐|抓手|赋能|颗粒度|高负|微服|连池" <刚写的文件>

## 通用输出
- 拿不准的 API、版本、参数、commit SHA、包名，先读代码或文档再答。
- 直接给结果，不写奉承开场和结尾客套。
```

## 完整词表（按需查，不常驻）

自检命令：

```bash
rg -n "不是.{0,20}而是|击穿|打穿|扛住|接住|拉齐|抓手|闭环|赋能|颗粒度|势能|范式|高负|微服|连池" <刚写的文件>
```

四类说法与替换：

| 类 | 命中就换 | 换成 |
|:---|:---------|:-----|
| 比喻当术语 | 击穿、打穿、扛住、接住、拉齐、抓手、闭环 | 失效、攻破、承受、承接、对齐、关键点、流程 |
| 生造词 | 高并发抗性、自解释度、容灾力 | 承受高并发、可读性强、容灾能力 |
| 过度缩写 | 高负、微服、连池 | 高负载、微服务、数据库连接池 |
| 抽象空泛 | 赋能、颗粒度、势能、范式 | 直接说做了什么、做到多细、往哪走、什么做法 |
| 对照句 | 不是 A 而是 B | 直接说 B（确实在纠错时才保留对照） |

注意"换词不换比喻"的失败模式：把"打穿防线"改成"防线被攻破"，比喻还在，只是换了个更书面的动词。命中这类词时先看整句是不是一个比喻，是就把比喻一起拆掉。

## 依据

| 决定 | 依据 |
|:-----|:-----|
| 不放字符级禁令（禁引号、禁 em-dash） | GB/T 15834—2011 §4.8.2 规定双引号就是 U+201C/U+201D，§4.8.3.2 允许引号做强调，§4.8.3.3 允许标示简称；禁字符等于禁国标许可的用法，且 vault 里已有 13975 处在用 |
| 词表写成"命中就换"+ 自检命令，不写成"禁止出现" | arXiv 2601.08070：点名禁词反而激活它，87.5% 的违规是 priming；机械检查放在生成之后才有效 |
| 保留"不是…而是…"这条 | fuck-slop 列为第一号 AI 指纹，de-ai-cn 七类模式第 1 类，社区 chinese-ai-humanizer 也排第一 |
| 常驻只留四类各两个例子，完整清单移到本文件 | writing-for-agents 的 progressive disclosure：每个分支都要用的留在正文，只有写中文长文才用的推到指针后面 |
| 删掉"拒绝任何AI味""少用抽象模糊空泛的词" | no-op：模型回读时看不见自己的 AI 味，只有机械扫描可靠（fuck-slop 原文） |
| 四个要点各配一个锚词（先摆假设、最小可用、最小 diff、目标可验证） | writing-for-agents 的 leading word：用预训练已有的词锚定行为，重复 token 而非重复句子 |
| 否定句只留硬护栏（不动相邻代码、不重构没坏的东西、不给黑话加引号） | 同技能：否定会把被禁行为拉进上下文，只有无法正面表述的硬护栏才用，并配正面目标 |
| 删掉"弱目标会换来反复澄清"这类解释 | 解释不改变行为，删掉省 context load |
